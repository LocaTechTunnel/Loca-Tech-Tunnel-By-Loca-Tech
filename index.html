¿Qué es LocaTech?

LocaTech Tunnel es una herramienta ligera desarrollada en Node.js diseñada para exponer servidores locales de desarrollo de forma instantánea a internet de manera segura y eficiente.

Ideal para desarrolladores que necesitan probar webhooks, mostrar avances en tiempo real o conectar servicios locales sin complicaciones de configuraciones de enrutamiento complejas.

Características Principales

  • Despliegue Instantáneo: Conecta tu puerto local a una URL pública en cuestión de segundos mediante comandos directos.
  • Subdominios Personalizados: Opción para solicitar y asegurar enlaces específicos adaptados a tus necesidades de prueba.
  • Máxima Privacidad: Arquitectura optimizada para enrutar el tráfico de forma anónima y segura.
  • Multiplataforma: Totalmente compatible con entornos de terminal modernos, incluidos sistemas Linux y emuladores móviles avanzados.

Instalación y Uso Global

Podés instalar la herramienta directamente desde el registro oficial de Node Package Manager (NPM) ejecutando el siguiente comando en tu terminal:

npm install -g locatech-tunnel

Para poner en marcha un túnel apuntando a un puerto específico de tu localhost (por ejemplo, el puerto 3000), utilizá:

locatech --port 3000

Si deseas solicitar un subdominio personalizado al iniciar el túnel, añade la bandera correspondiente:

locatech --port 3000 --subdomain mi-app-custom
